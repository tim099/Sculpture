## 圖紙與來源

`deck_plan.png`按0.1m格、+X船首、−Y左舷繪製；編號、名稱、座標、比例對應`placement.json`。兩燈刻意放大至2.7m高作為艉樓信標，燈芯沿來源wick固定點發光。左右繫纜柱轉90°，使用pivot=[0,41,0]，避開狹窄艏樓的既有構件。
