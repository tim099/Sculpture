# 松島號（Matsushima，1892；1894 年黃海海戰聯合艦隊旗艦）—— 作品筆記

委託（Tim 2026-10-21，TASK-0780）：「按照遊戲用的規格造船吧 建造 甲午海戰時，日本聯合艦隊的旗艦防護巡洋艦松島號 參考裡歷史資料與圖紙 最後由妳繪製圖紙並建造(資訊不足的部分由妳設計) GO」

- 範圍：照 1894 年 9 月黃海海戰時的樣子（1901–02 換 Belleville 鍋爐、拆桅樓之前）；史料查不到的由 ridge-001 設計，每個數字在 `design/plan.json` 的 provenance 標「原圖讀數／參考資料／設計決定」。
- 範本：同一場海戰的定遠號（trailhead，`trailhead-dingyuan-01m/design/`）—— 產生程式的結構照它改寫，船形、甲板層、上層建築、機艙、桅都換成松島號的。

## 產生程式（`design/`，重跑逐位元組相同）

```bash
python -I -X utf8 -B gen_parts.py <parts 輸出>            # 砲、主砲殼、旭日旗貼圖
python -I -X utf8 -B gen_matsushima.py <gen 輸出>         # 整艘的格子 → part_*.txt、own.npy、matsushima_meta.json
python -I -X utf8 -B place_guns.py <gen 輸出> <parts 輸出>  # 每門砲退到零碰撞、小艇、錨 → guns.json（--shift=3 反向對照）
python -I -X utf8 -B check_arcs.py <gen 輸出>              # 主砲射界 → arcs.json（--shift=3 反向對照）
python -I -X utf8 -B draft_blueprint.py <gen 輸出> <parts 輸出> <png>   # 新圖紙
python -I -X utf8 -B apply_build.py <gen 輸出> <parts 輸出> [部件…]     # 建子作品、照清單同步格子（只動差的）
python -I -X utf8 -B apply_links.py <gen 輸出> <parts 輸出>             # 關聯、meta、固定點、模型、繩、旗、preset
```

⚠ `gun37.txt` 與三件小艇／錨的清單是 `op=export format=list` 從來源作品匯出到 parts 輸出資料夾的（`place_guns.py`、`draft_blueprint.py` 要讀）。

## 讀數（2026-10-21）

- 組裝件：2,118,740 格、6 連通 **1 塊**、封閉空腔 **0**；`link_overlap` 0、`link_clipped` 0；鍋爐／主機／軸鏡過去落在別的部件 0 格。
- 鏡像差 y:90：558／470 格、36 格顏色不同 —— 全是不對稱的梯子與艙口（lm-mid、mu-mid 在右舷、uf-mid 在左舷）、海圖室門，照實留著。
- 排水量（設計水線以下的外形）**4,332 t** —— 史料 4,217 長噸（Conway's）／4,278 長噸（1894 年 6 月，《海軍軍備沿革》）；方塊係數 0.48、中剖面係數 0.86。
- 全長 99.2 m（衝角尖到船尾）、水線長 92.4 m（史料 91.74）、寬 15.6 m、吃水 6.1 m。
- 主砲：量出來轉 ±142°、開火 ±139°（史料「左右各 140°」）；meta 寫 `arc=-140,140`、`fire=-139,139`。擋住的：船首樓後端兩門 57 mm、桅、whaleboat。砲罩掃過的圓柱裡別的格 0。反向對照：障礙往 +x 挪 3 格 ⇒ 轉 ±146°、開火 ±140°。

- 部件：關聯 29、模型 70（砲 27、火藥桶 32、小艇 4、錨 2、螺旋槳 2、舵、舵輪、羅經櫃）、固定點 223。

## 設計決定（史料查不到的）

- 1894 年 9 月的塗裝沒有文字史料：照 1893 年嚴島照片（白殼黑煙囪）、1895–96 年松島照片（全身淺色）、1895 年黃海海戰的畫（淺色船身、深色煙囪）⇒ 白殼、白上層、黑煙囪、白桅、水線一條黑、水線下紅丹。
- 輕砲的位置：57 mm 每舷兩座船首樓側面的突出砲台（照片 P1895、P1896 看得到開口）＋船首樓後端各一門；47 mm 兩層桅樓各兩門、後甲板船尾兩門；37 mm 轉膛砲艦橋兩翼各一門（ja Wikipedia 的 infobox 寫 2 門 37 mm）。
- 桅樓：照片的桅樓高約 2.4 m；做成下半 0.8 m 的牆＋0.5 m 射擊縫＋上半一圈裝甲帶、四根撐柱 ⇒ 47 mm 從縫裡開。
- 鍋爐排法（兩舷各三、爐門朝中線）、主機位置、彈藥庫位置、螺旋槳 3.2 m、舵的大小、小艇艘數。
- 魚雷管（艏 1、艉 1、兩舷各 1）只畫成外板上的黑圈，遊戲沒有魚雷。
