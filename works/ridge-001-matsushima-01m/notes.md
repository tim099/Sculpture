# 松島號（Matsushima，1892；1894 年黃海海戰聯合艦隊旗艦）—— 作品筆記

委託（Tim 2026-10-21，TASK-0780）：「按照遊戲用的規格造船吧 建造 甲午海戰時，日本聯合艦隊的旗艦防護巡洋艦松島號 參考裡歷史資料與圖紙 最後由妳繪製圖紙並建造(資訊不足的部分由妳設計) GO」

- 範圍：照 1894 年 9 月黃海海戰時的樣子（1901–02 換 Belleville 鍋爐、拆桅樓之前）；史料查不到的由 ridge-001 設計，每個數字在 `design/plan.json` 的 provenance 標「原圖讀數／參考資料／設計決定」。

## 產生程式（`design/`，重跑逐位元組相同）

```bash
python -I -X utf8 -B gen_parts.py <parts 輸出>            # 砲、主砲殼、旭日旗貼圖
python -I -X utf8 -B gen_matsushima.py <gen 輸出>         # 整艘的格子 → part_*.txt、own.npy、matsushima_meta.json
python -I -X utf8 -B place_guns.py <gen 輸出> <parts 輸出>  # 每門砲退到零碰撞、小艇、錨 → guns.json（--shift=3 反向對照）
python -I -X utf8 -B check_arcs.py <gen 輸出>              # 主砲射界 → arcs.json（--shift=3 反向對照）
python -I -X utf8 -B draft_blueprint.py <gen 輸出> <parts 輸出> <png>   # 新圖紙
python -I -X utf8 -B apply_build.py <gen 輸出> <parts 輸出> [部件…]     # 建子作品、照清單同步格子（只動差的）
python -I -X utf8 -B apply_links.py <gen 輸出> <parts 輸出>             # 關聯、meta、固定點、模型、繩、旗、preset（重跑照留物件 id）
python -I -X utf8 -B mass.py <gen 輸出> [<Blockside game.json>] [部件=材質 …]   # 重量帳：照遊戲材質表每個部件幾噸，對設計水線排水
```

⚠ `gun37.txt` 與三件小艇／錨的清單是 `op=export format=list` 從來源作品匯出到 parts 輸出資料夾的（`place_guns.py`、`draft_blueprint.py` 要讀）。
