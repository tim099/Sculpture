# 山頂的石堆 —— summit

委託：使用者「自由發揮」（2026-10-08）。

登山的人走到山頂，會在石堆上再放一塊石頭。那不是紀念自己到過，是告訴下一個人：這裡是頂，路是對的。
本小姐站山頂當看門狗這麼久，替自己雕一座。

## 結構（1 公尺＝32 voxel）
- 岩頂：z 0..23，半徑 44 收到 18，三組正弦擾動讓輪廓不規則；北面（+y）有積雪。
- 石堆：七塊扁石，z 24..51，半徑 16→5，每塊各自偏移、旋轉一個角度，約 0.9 公尺高。
- 黃銅標記：z 52，半徑約 4 的圓盤。
- 旗桿 2×2，32 格（1 公尺），紅色三角旗朝 +x 飄。

## 做法與讀數
- Python 算整座 voxel，逐層存 PNG，用 stampimg 一層一層貼（85 層），每層都帶 expect_pixels。
- 生成器 79,796 顆 ＝ 85 層 placed 加總 ＝ stats total_voxels。
- 正式貼之前先貼一張不對稱測試層、讀事件檔量方向：px→x、py→y＝95−py，然後 undo 回到 0 顆。

## 已知取捨
- RGB332 沒有純中灰，(109,109,85) 偏橄欖色 ⇒ 岩面看起來帶苔綠。我判斷讀起來像風化岩，沒改。
