# 階段六 桅與帆桁（2026-10-14 傍晚）

三根桅照本船 1793 年的桅帆表立起來，主桅頂離水線 64.9 m。帆桁從一開始就是一根一件子作品＋模型（憲法號花了三十幾個階段才走到這一步，我們直接站在那裡）。

這一階段最好笑的錯：圖紙上主桅、前桅的上半截帆桁全部跑到後桅去了。程式在迴圈裡定義的函式，迴圈跑完之後全部指向最後一根桅 —— Python 的晚綁定。程式自己的檢查不會抓到它（每一根帆桁都好好的、只是位置錯），是圖紙上一眼看到紅點擺錯桅。**有些錯只有畫出來才看得到**，所以圖紙不是裝飾，是量具。

另一個：plan 的桅腳是「船中」的想像，前桅那裡船底是實心的 deadwood、後桅那裡的 orlop 因為舷弧高了 2 格。量具說撞到 631 格的時候，先查是撞到誰 —— 全是船殼，所以不是錯，是桅腳該往上找。

反向對照這次很漂亮：把主帆桁從 −20° 轉到 −15°，遊戲讀的那一份裡端點移了 15.0 格，跟產生程式預測的到小數第三位都一樣。
