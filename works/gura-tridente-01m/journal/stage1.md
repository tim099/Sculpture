# 階段一 新圖紙（2026-10-14，wake #88）

Tim 一句「建造屬於你的船吧」，船型指名最大的一級戰列艦。本小姐第一個想的是：要不要像餘燼號那樣拿現成的船改？量了一下就放棄了 —— 餘燼號的寬是憲法號的 13.3 m，聖特立尼達號是 16.2 m，四層砲列硬塞進窄船會變成一個又高又窄的盒子。所以線形自己畫：一個船中剖面、往兩頭收、兩端往上抬成 deadwood。

## 查證
派了兩個研究 agent 各自查，第二個專門找出處之間的矛盾。值得記的：
- 第二個找到**本船的桅帆表**（Mejías Tavero 1793，經 UPC 論文轉載）—— 本來打算拿 Victory 當替代，結果不用了。
- 第二個也找到「下層砲門離水面 5-08（1.58 m）」—— 這一格直接決定了下砲甲板的高度（z 87 → 89）。
- Todo a Babor 的公制數字整體大了 3%（換算錯），El Debate 抄了它；英呎數其實是對的。
- 「140 門」裡有 obús；「四層」是四層砲列、不是四層有蓋甲板。
- 目擊者那句「four distinct lines of red, with a white ribbon between them」—— 一個 agent 說 Lovell、一個說 Badcock，其實應該是同一個人（後來改姓），本小姐記憶，沒查證。

## 線形調了三次
1. 第一版兩端的剖面有一層水平的「平台」：deadwood 抬到 zr 之後，圓底從 keel 寬直接長出去。⇒ 兩端剖面的指數往 1 收（V 形）、再加一點酒杯形。
2. 第二版在 z 84 還是有一層：wing transom 的寬在每一站都在同一個高度轉過去。真船只有最後那一站是一道 counter，往前 buttock 平順地爬上去 ⇒ 轉的那一段越往前越長、越低。
3. 排水量只有 4,418 t（目標 4,902）⇒ 平行中段放長（0.32／0.60 → 0.26／0.66）、圓舭指數 2.4 → 2.8 ⇒ 4,952 t。

## 反向對照
半寬加 3，每一站、每個高度都報 +3；推一個砲門 3 格，間距讀數 22 → 19／25。報得出來，尺是活的。
