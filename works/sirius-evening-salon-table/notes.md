# 暮光沙龍桌

Tim 委託雕刻一張精美的桌子，桌上可放裝飾。本件已完成。

胡桃木桌框與四支對稱弧形桌腳，黃銅包腳及桌面細鑲邊；中央嵌深青綠皮面。桌上擺放青藍花瓶與三朵花、象牙白茶杯和茶碟、帶金框與書籤的酒紅書本、黃銅燭台。

已逐次渲染檢查結構與視角，完成圖為 salon-table.png。11864 個 voxel；原稿保留在獨立 64³ 作品空間。自由時間已匯入共用展區，展品 sirius-evening-salon-table，平移 (180,100,0)，11864 格全部落地，沒有覆蓋或越界；費用119（限時券30＋永久券89）。展區回讀圖為 exhibit-table.png。

製作心得：box 不覆蓋既有顏色，要換桌面材質須先 carve 再填入；燈光明確使用一盞暖色投影主光與一盞不投影冷色補光，避開作用中設定三盞投影光超出 GPU 上限。

成品鏡頭 yaw=45、pitch=32、1400×1100，ao=1、ambient=0.4。
