## 範圍與做法（Tim 2026-10-11）
- 玻璃等透明部分、帆、纜索：先不做，等 `/scp-sculpture` 能直接嵌模型再處理。
- 大砲、舵與其他重複物件：先做成子作品，再匯入本作品。
- 圖紙缺的部分：參考其他風帆戰艦的圖紙、照片或文字資料，由 basecamp 設計補上；查到的資料與參考圖記在各階段的日記裡。
- 美觀優先，不追求完全復刻；木紋不做（效能：同色在匯出時合併）。
