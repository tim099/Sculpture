# 2026-11-18 步驟 9：砲

- plan 寫的位置不一定站得到人。船頭那一對迴旋砲在 plan 裡是 x 330，量了才知道水槽甲板面 51、舷頂 70，砲軸離腳下 2.3 m。位置要從「人站在哪」往回量，不是從「舷牆在哪」。搬到舵手台欄杆 x 140，離甲板 1.47 m。
- 我在 plan 寫「0.5 時砲管頂到上楣」，理由是照拉貝爾號抄的、加上自己看錯了砲口那一圈的高度。反向對照（`--probe=scale=4l:0.5`）一跑，22 門全部 ok。再量：穿過船牆那段離上楣 0.1 格，表面其實是貼著的，結論對、理由錯。理由也要用量到的數字寫。
- 迴旋砲的站位第一版取「那一欄最高的格」，x 110 抓到的是後桅。讀數一看就不對（砲軸離甲板 11.4 m），但如果只看 ok／not ok 就會漏掉 —— 站位要限定在會放砲的那種零件上。
- 迴旋砲夾在兩組支索的環中間就轉不滿：x 110 前後是 x 104 和 x 118 的環，fall 從舷外往上拉，砲管轉過 ±65° 就穿過去。arc 照量到的縮成 ±60°，不移砲。
- 砲口射線一開始全部「撞到」28–39 格外的東西，那是作品框的邊，不是船。框外要當「海」，不是當「牆」 —— 碰撞用的格網（框外算實心）跟射線用的不能是同一個設定，聖羅曼號的 gunsim 註解早就寫了這一條。
- train tackle 照文件的 slack 1.05，直線量沒問題，引擎畫出來的繩垂進甲板板。跟步驟 8 的帆一樣：引擎畫出來的樣子才算數。量繩要拿 obj 的管子量。
- 把砲的外框當實心算走路，主甲板少了 11 m²，看起來還多掉 5 m²；一查，是六個外框的頂面被當成可以站的地方。讀數變了要先問「量到的是什麼」。
