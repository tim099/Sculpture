# 加勒比海風格城鎮建築套件（carib）—— 續作筆記

TASK-0757（2026-10-20，summit）。規格：Blocksail `docs/BUILDING_SPEC.md` §6.3；史料：本作品 `references/`。

## 做了什麼
- 托爾圖加這座村用得到的六種：住宅 A／B／C＋配色變化 A2／B2／C2、酒館、倉庫、小教堂、長官的屋子、砲台。
- 新部件 4 件：木板百葉窗、欄杆窗、木板門、雙扇木板門。貨門、氣窗借法式套件。
- 小件借岩堡港：燈籠、酒桶、貨箱、燻肉架。砲借風暴角號 6 磅砲。
- 長官的屋子、砲台各一面白色布旗。

## 照史料改過的（第一版 → 讀完史料）
- 住宅 A：石墩架高沒有史料，改成毛石台基＋三級切石台階（Labat 的住屋）。
- 住宅 B：改成 Labat 的標準小屋。山牆朝街，門與唯一一扇窗都在山牆；屋頂垂到近地。
- 倉庫：毛石牆沒有史料，改成木板牆＋essente。
- 小教堂：改成毛石到 1.1 m、上面開敞（Du Tertre）；聖所與正面釘板；欄杆窗代替玻璃；加長凳、祭壇、聖器室；墓地沒圍牆。
- 長官的屋子：從兩層樓改成一層四間的釘板木屋（Fort Louis）＋木樁柵欄（Grenada）。
- 砲台：改成兩排木樁夾土的胸牆（Fort Louis），砲眼頰用 gabion。
- 配色：遮板的紅、綠、藍沒有史料，拿掉；只留刷石灰白、沒刷的泥牆。

## 怎麼重產
```
python -I -X utf8 -B build.py <design>       # 產清單、圖紙、manifest、verify
python -I -X utf8 -B apply.py <design> create|stamp|anchors|links|models|sails|check
python -I -X utf8 -B render.py <design>      # 引擎預覽圖 → overlays/
```

## 坑
- 部件的框在開口外面一格 ⇒ socket 要包住框，不然框壓到牆（撞格 348）。
- 門扇跟框只斜角相碰 ⇒ 部件自己 2 個元件 ⇒ 框往裡深一格當鉸鏈（BUILDING_SPEC §10 第 3 條同一件事）。
- 關聯記著來源當時的框（links.json 的 pivot）；來源縮了框，`overwrite=1` 不會更新它 ⇒ 縮框被擋 ⇒ apply.py 對不上就拿掉重下。
- 已經有的關聯、外部模型，只改替換色或位置也要 `overwrite=1`。
- 組裝件的固定點清單會列出關聯底下的（名字帶 /），不是這一件的 ⇒ 清舊固定點時跳過。
- RGB332 在引擎打光下：141 看起來偏粉紫、137 是洋紅 ⇒ 板牆改 109、木瓦改 104／100／68。
