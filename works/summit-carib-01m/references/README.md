## 顏色（只有幾種站得住）

照報告 §8：
- 有時代證據：石灰白、未上漆的灰褐木材與木瓦、草葉屋頂的稻草色、土牆。
- 推測：未上漆的木板曬成灰（板牆用 RGB332 109），木瓦用褐色（104、100、68）。
- 遮板與門的彩色漆：**沒有證據** ⇒ 這一套不用（第一版的紅褐、綠、藍拿掉了）。
