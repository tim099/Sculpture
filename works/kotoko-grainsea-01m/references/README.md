# 史料 —— 資源建築 B 糧與海（TASK-0927）

這一批**沒有上網查**。每一格寫照什麼：〔通論〕＝各地常見的做法、〔設計〕＝我定的、〔沒查到〕＝想查的東西沒有來源。

## 磨坊（common：畜力磨）
- 加勒比海的法屬、英屬城沒有能架水車的河，風車也少見 ⇒ 牲口拉的磨（manège、horse mill）〔通論〕。
- 17 世紀加勒比海的穀物磨坊〔沒查到〕。當地麵粉多半靠船運，玉米、木薯在家裡手磨〔通論〕。
- 立軸直接帶上磨石、圓錐頂、牛走的環道〔設計〕。真的畜力磨多半有一組齒輪（大的冠輪帶小的燈籠齒輪）；這裡省掉了。

## 磨坊（roman：塔式風車，君士坦丁堡 1453）
- 愛琴海一帶的塔式風車：石砌圓塔、圓錐頂、八根輻、三角帆布綁在輻上〔通論〕。
- 1453 年君士坦丁堡城裡磨坊的樣子〔沒查到〕。城裡也有牲口磨，引水渠沿線有水車。
- 牆用方石夾磚帶，跟 `kaguya-roman-1453` 的城牆同一套色，這樣跟城擺在一起不突兀〔設計〕。

## 漁場
- 拖上岸的小划船、晾網架、剖魚的長桌、醃魚桶、編的魚簍〔通論〕。
- 17 世紀加勒比海漁家的棚〔沒查到〕。尺寸、配置〔設計〕。

## 鹽田
- 海鹽一級一級濃縮：蓄水池 ⇒ 蒸發池 ⇒ 結晶池；結晶池裡把鹽耙成小堆〔通論〕。濃縮中的鹵水帶粉紅色，是池裡的藻〔通論〕。
- 加勒比海（Tortuga、Salt Tortuga、Turks 一帶）17 世紀有耙鹽的天然鹽池。只讀過「有這些鹽池」，池子長什麼樣〔沒查到〕。
- 4 欄 × 3 排的池子、木板鹽倉〔設計〕。
